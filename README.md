# ASMR 双耳空间化（asmr_binaural.py）

把任意人声处理成"有人在你耳边 / 身边说话"的效果，用耳机听。立体声输入只取一个声道（默认取更响的那个）再做空间化。

```bash
uv run asmr/asmr_binaural.py 输入.wav                          # 默认：贴耳加强，左右耳慢慢穿梭，忽远忽近 → 输入_asmr.wav
uv run asmr/asmr_binaural.py 输入.wav --style ku100            # 像真实 KU100 实录：远耳听得到，离耳约 6 cm，有房间
uv run asmr/asmr_binaural.py 输入.m4a -o 输出.wav --mode wander  # 在你身边走动着说话
```

第一次运行时，uv 会安装 numpy / scipy / h5py；如果 `hrtf/` 里没有数据，会从 Zenodo 下载约 16 MB 的 HRIR，然后生成预处理缓存（约半分钟）。之后处理 1 分钟音频大约 2 秒，62 分钟音频约 2.5 分钟。

## 默认效果：贴耳加强（D2）+ 忽远忽近

默认设置来自试听反馈（D 版"贴耳加强"效果最好），再按论文做了增强：

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 嘴离耳朵约 1.7 cm，远耳再压低 32 dB，声音干、不加房间 | 真实 KU100 贴耳录音两耳差 31–38 dB；Shimokura 2022：越"近"、两耳越不相关，ASMR 越强 | `--dist`（0.105）`--isolation 32` `--room none` |
| 远耳 320 Hz 以下再压 12 dB、近耳低频加 5 dB | Brungart & Rabinowitz 1999：近处距离感主要靠低频两耳差；Honda 2020：128 Hz 两耳差的起伏与战栗感 r=0.93 | `--far-lf-cut 12` `--ear-warmth 5` `--warmth 6` |
| 25 cm 以内按"从每只耳朵看出去"的方向取耳廓响应（声学视差） | Romblom & Cook 2008；Spagnol 2017：视差在 20 cm 以内才明显 | 内置 |
| 贴耳位置略靠后（100°） | Kitagawa 2005：脑后近处的声音与触觉交互最强 | `--ear-angle 100` |
| 约 1/4 的换边改成"先退到约 0.5 m，再用 2–3 s 凑到耳边" | Serino 2015：逼近的声音进入身体周围 43–62 cm 后会增强触感；Honda 2020：移动比静止更易引发战栗 | `--approach 0.25` |
| 每只耳朵停 2.5 s，用 2.5 s 移到另一边，保留 20% 的响度随距离变化 | Spagnol 2017：响度是最强的距离线索；Honda 2020：慢转（18°/s）和快转（72°/s）效果相同 | `--hold-time 2.5` `--move-time 2.5` `--level-follow`（0.2） |
| 响度 −16 LUFS | 参考视频 −15.6 LUFS | `--lufs -16` |

### 忽远忽近（默认开启）

真人在耳边说话不会一动不动：贴着耳朵说一会儿，往后让一点，再凑回来。程序在左右穿梭的基础上让嘴到耳朵的距离一直在变（只改距离，方向不变），由两部分叠加。动起来本身就有用：Honda 2020 发现声源离耳 6 cm 移动时比静止更容易引起战栗感，与两耳差起伏的相关 r=0.93；Shimokura 2022 发现 ASMR 强度与"感觉有多近"相关 r=0.93。

| 做法 | 依据 | 参数（默认值） |
|---|---|---|
| 随机的"贴耳停留 → 慢慢往后让 → 稍停 → 慢慢凑回来"，循环往复。每段时长、退开深浅都随机：多数退到 3.5–7 cm，偶尔 7–16 cm，偶尔只让一点；一个来回平均约 7 s，凑回来比退开慢 | KU100 实录（本项目测量 7 段）：两耳差起伏的标准差约 5.5 dB（约 ±1 倍距离），一个来回 2–23 s、中位 4–9 s。Lundbeck 2017：远近运动要约 2:1 的距离变化才听得出，所以退开幅度取 2–4 倍。逼近比远离更引人注意、听起来更快（Neuhoff 2016 综述；Ghazanfar 2002），所以凑回来比退开慢。脸周围的身体周围空间约 50–60 cm（Serino 2015），逼近越快范围越大（Noel 2018：52–77 cm），1–40 cm 全在其中 | `--sway 1` `--sway-period 7` |
| 跟着说话音量：声音大的地方提前往后让（每响 6 dB 退远一倍，约提前 0.8 s），说完约 2.5 s 后才慢慢凑回来；轻声时更贴近 | 真实说话人离听者越远说得越大声、越近越轻：自然说话时每远一倍提高 1.3–2.2 dB（Pelegrín-García 等 2011）；响的字不会贴着耳朵炸出来，整体响度更均匀 | `--sway-follow 1` |
| 退开时耳边音量只保留物理衰减的 45%（说话人退开会不自觉地说大声一点）；房间声跟着说话人的音量走而不跟距离走，所以直达声 / 房间声之比按物理规律变化 | 自然说话人只补偿 1.3–2.2 dB/倍，耳边约每远一倍衰减 4 dB，即保留物理衰减的 65–75%（Pelegrín-García 等 2011）；ASMR 成品还经过压缩，KU100 实录只保留 40–56%（BV1X4ZyBREqr 56%、BV1XHBXBaEmt 40%、BV1hBsP6FE1g 44%）。这里取 45%，想更像自然说话可用 `--sway-level 0.7`。不能完全拉平：Arend 2016 发现把响度拉平后，听者分不出 0.25–1.5 m 的远近。说话人音量的变化加在混响送出之前，所以每靠近一倍，混响 −2 dB、直达声 +4 dB、直达 / 混响比 +6 dB（Kolarik 2016 综述；Zahorik 2002：直达 / 混响比的最小可察觉差 5–6 dB） | `--sway-level 0.45` |
| 远耳随距离自然"打开"：贴耳时几乎听不到，往后让时逐渐听得到，近耳的低频和临场感随之减弱 | Brungart & Rabinowitz 1999：近处侧方声源的距离感主要靠两耳差，500 Hz 两耳差从 1 m 处约 4 dB 增大到 0.125 m 处约 25 dB；Kan 等 2009：40 cm 以内的侧方声源，按距离变化函数渲染明显好于只改音量 | 内置 |

实测（病娇音声前 1 分钟）：
- 贴耳时离耳 0.9–8.7 cm（中位 2.8 cm），偶尔退到 20 cm 以上。
- 距离变化速度中位 2.3 cm/s，90% 在 11 cm/s 以内。Honda 2020 发现 2 cm/s 和 8 cm/s 引起的战栗感相同；身体周围空间的逼近实验用 22–75 cm/s。
- 贴近停留中位 3.1 s。Koumura 2021：战栗感比声音滞后约 2 s。
- 最响 1% 的瞬时响度比中位数高 10.0 dB（不晃时 11.3 dB）。

`--sway 0 --sway-follow 0` 可完全关闭，结果与旧版默认逐样本相同。

文献（DOI）：Pelegrín-García 等 2011 JASA [10.1121/1.3552881](https://doi.org/10.1121/1.3552881)；Arend 等 2016 Tonmeistertagung（KU100 近场 HRIR 的感知评测，[Zenodo 4297951](https://zenodo.org/records/4297951)）；Lundbeck 等 2017 Trends Hear [10.1177/2331216517717152](https://doi.org/10.1177/2331216517717152)；Neuhoff 2016 CRPI [10.1186/s41235-016-0017-4](https://doi.org/10.1186/s41235-016-0017-4)；Ghazanfar 等 2002 PNAS [10.1073/pnas.242469699](https://doi.org/10.1073/pnas.242469699)；Serino 等 2015 Sci Rep [10.1038/srep18603](https://doi.org/10.1038/srep18603)；Noel 等 2018 J Neurophysiol [10.1152/jn.00652.2017](https://doi.org/10.1152/jn.00652.2017)；Kolarik 等 2016 APP [10.3758/s13414-015-1015-1](https://doi.org/10.3758/s13414-015-1015-1)；Zahorik 2002 JASA [10.1121/1.1506692](https://doi.org/10.1121/1.1506692)；Brungart & Rabinowitz 1999 JASA [10.1121/1.427180](https://doi.org/10.1121/1.427180)；Kan 等 2009 JASA [10.1121/1.3081395](https://doi.org/10.1121/1.3081395)；Honda 等 2020 Front Psychol [10.3389/fpsyg.2020.00316](https://doi.org/10.3389/fpsyg.2020.00316)；Koumura 等 2021 QJEP [10.1177/1747021820977174](https://doi.org/10.1177/1747021820977174)；Shimokura 2022 Audiol Res [10.3390/audiolres12050056](https://doi.org/10.3390/audiolres12050056)。

### KU100 实录风格 `--style ku100`

按两段 KU100 实录（B 站 BV1X4ZyBREqr、BV1XHBXBaEmt，五月织姬）标定。这两段有明显底噪（低频比说话低 30–36 dB），统计前先按频段扣除了底噪；它们的音频不会混入输出，程序本身也不加任何底噪。与默认的贴耳加强相比：远耳不额外压低（`--isolation 0`）、贴耳距离约 6 cm（`--dist 0.15`）、远耳低频不额外压（`--far-lf-cut 0`）、KU100 实测真实房间（`--room real`）、KU100 原机音色（`--headphone native`），忽远忽近照常。每一项都可以单独再指定来覆盖。

| 统计（扣除底噪后） | 两段 KU100 实录 | `--style ku100` | 默认（贴耳加强） |
|---|---|---|---|
| 0.5–2 kHz 两耳差 p10 / 中位 / p90 | 1.6 / 11–12 / 21 dB | 4.6 / 15.4 / 20.7 dB | 3.7 / 41 / 61 dB |
| 150–500 Hz 两耳差 p10 / 中位 / p90 | 0 / 7–9 / 18–20 dB | 1.9 / 13.8 / 21.3 dB | 1.4 / 43 / 69 dB |
| 两耳差起伏：标准差，自相关降到 0.5 的时间 | 5.5–5.8 dB，1.5 s | 5.3 dB，1.5 s | 18 dB，1.5 s |
| 退开时近耳音量保留的比例 | 40–56% | 45% | 45% |

剩下的差别主要因为实录里约 25% 的时间人在正前方说话，而 sweep 一直在两耳之间来回。

可选的对比开关：
- `--dark 4`：贴耳时近耳 5 kHz 附近压低 4 dB，音色更"暗"（Koumura 等：频谱重心低于 1.5 kHz 的暗音色与 ASMR 相关；Terashima 2024：5 kHz 附近能量越低，刺痛感越强）。
- `--room treated --wet -12`：加一点点房间声（Kopčo & Shinn-Cunningham：侧方声源的距离感靠两耳差，正前方的声源靠房间声）。

### 真实感（用参数打开）

| 参数 | 做什么 | 依据 |
|---|---|---|
| `--room real` | 用 TH Köln 以同一个 KU100 在真实房间实测的双耳房间脉冲响应（12 个方向，去掉直达声，混响时间按频段缩短到卧室水平约 0.35 s），电平按 KU100 贴耳录音实测定：贴耳时远耳听到的房间声比近耳低约 28 dB，且两耳不相关 | 真实 KU100 贴耳录音里远耳并不安静：比近耳低 23–35 dB，主要是房间声（本项目实测）；Larsson、Västfjäll、Kleiner 2008：房间线索提升临场感与头外感；Werner 等：房间声学与预期不符会降低头外感 |
| `--soft-voice 1` | 轻声化：按 ANSI S3.5 不同说话力度的标准频谱，把嗓音均衡到"压低声音说话"（中频略收、低频更饱满、最高频气声略多），只做均衡 | Brungart & Scott 2001（JASA）：说话声的距离感主要取决于说话力度，力度每增加 15 dB 听起来远一倍，播放音量几乎不影响；耳语 / 轻声听起来最近 |

`--style ku100` 默认就带 `--room real`。人为合成的底噪（`--room-tone`）、吸气声（`--breath`）、气音（`--breathy`）、气流声（`--airflow`）听起来不真实，已从程序中删除。

数据来源：`data/room_audiolab_ku100.npz` 提取自 Lübeck, Arend, Pörschmann (2021) "A High-Resolution Spatial Room Impulse Response Database"（[Zenodo 5031335](https://zenodo.org/records/5031335)，BRIR_Audiolab_LSC_KU100_P1，CC BY 4.0），去掉了直达声并缩短了混响时间。

### 硬件模拟（默认关闭，用参数打开）

| 参数 | 模拟的是什么 | 依据 |
|---|---|---|
| `--headphone native` | KU100 原机音色：不做扩散场补偿，保留 KU100 出厂内置均衡后的音色，和真实 KU100 录音一样（3–12 kHz 比默认暗 2–4.5 dB） | KU100 出厂即扩散场均衡；TH Köln 的 CDFC 是为了抹掉人头本身的音色（Bernschütz 2013）；"暗"的音色与 ASMR 相关（Koumura；Terashima 2024） |
| `--headphone HD600` 等 | 按耳机型号补偿：用 TH Köln 在同一个 KU100 上实测的 23 款耳机滤波器（`--headphone list` 查看） | Engel 等 2019：通用耳机补偿能减少染色、提升整体质量、改善距离感，效果接近个人化补偿 |
| `--puff 1` | 爆破音气团：送气音（p/t/k/q/ch/c）爆破后约 10 ms，气团扑到贴着的那只耳朵上，形成 20–200 Hz 的压力脉冲；嘴离开耳边时不出现 | Derrick 等 2009（JASA）测量了"pa"的气团和话筒"噗"声；去爆破音工具在 20–80 Hz 检测这类声音 |
| `--deess 6` | 去齿音器：只在"s/sh/x"等齿音出现时，把 4.5–11 kHz 动态压低（最多 6 dB），其他时刻和其他频段不动 | 贴耳的齿音很刺耳；Terashima 2024：5 kHz 附近能量越低，刺痛感越强 |

### 近耳高频校正（默认关闭）

`--ku100-eq`：近耳 6–12 kHz 改用按 B 站 5 个 KU100 贴耳录音（BV1taEf6cEfi、BV1hBsP6FE1g、BV1ZndxYSE4Z、BV1UccyzWEgH、BV19t411D7tQ，只提取统计特征）标定的校正曲线，高频更收。

## 和参考视频（BV1KPJDzHEVV）的区别

分析原视频音频发现，它的双耳时间差（ITD）全为 0，各频段的双耳声级差（ILD）也完全一样。也就是说，它只是左右**音量声像**，在"左→中→右"之间来回切，经常把一侧直接关到 −60 dB。这样听起来像声音在耳机里面，而不是有人在耳边。

本程序按真实声学来做：

| | 原视频 | 本程序 |
|---|---|---|
| 双耳时间差 ITD | 0 | 0–0.85 ms，随位置连续变化 |
| 头影 / 耳廓滤波 | 无（各频段 ILD 相同） | Neumann KU100 人工头实测 HRIR（很多 ASMR 用的就是这个人头） |
| 距离感 | 只有音量 | 0.25–1.5 m 实测近场数据，0.095–0.25 m 用球头模型外推并做声学视差；近处低频 ILD 更大、更干，远处房间声更多 |
| 运动 | 固定 3 秒周期的自动声像：每只耳朵停 1 秒，0.5 秒穿过中间 | 默认 2.5 秒经脸前慢慢移到另一只耳朵，在耳边忽远忽近，带多普勒和人体自然晃动；`pingpong` 可复刻原视频的 3 秒节奏 |
| 空间 | 无 | 卧室早期反射（跟随声源方向）+ 双耳去相关混响 |

在 `音频/asmr_ref/demo/` 里有同一段内容的 A/B 对比（A = 原视频，B = 本程序处理，响度已基本对齐）。

## 运动模式 `--mode`

| 模式 | 效果 | 相关参数 |
|---|---|---|
| `sweep`（默认） | 贴左耳停一会儿 → 经脸前慢慢移到右耳 → 停 → 移回，持续不断；偶尔先退远再凑近 | `--move-time`（2.5 s）`--hold-time`（2.5 s）`--ear-angle`（100°）`--approach`（0.25）`--via front/back/alternate` `--pass-dist`（0.2 m）`--dist` |
| `phrase` | 只在说话停顿处换位置（移动藏在停顿里，听起来像跳过去）：左耳 ↔ 右耳为主，偶尔到侧前方、侧后方、正前方 | `--min-gap` `--min-hold` `--max-hold` `--seed` |
| `pingpong` | 参考视频的节奏：3 秒一个来回，每只耳朵停约 1 秒，约 0.5 秒穿过中间 | `--period`（默认 3）`--via` `--dist` |
| `orbit` | 绕头转圈 | `--radius`（默认 0.35 m）`--period`（默认 12 s）`--ccw` `--az`（起点） |
| `wander` | 在你身边走动，0.25–1.2 m | `--seed` |
| `static` | 固定位置 | `--az` `--dist`（默认左耳 270°、0.15 m） |
| `path` | 按关键帧走 | `--path 轨迹.json` |

方位角 `az`：0 = 正前，90 = 右，180 = 正后，270 = 左（顺时针，单位为度）。距离 `dist`：到头中心的米数，范围 0.095–3。耳朵本身离头中心约 0.09 m，所以 0.105 m 就是嘴贴着耳朵（默认的贴耳距离）。

`path` 模式的 JSON 示例：相邻两个关键帧之间做平滑移动；如果想停住，就连写两个相同位置。

```json
[
  {"t": 0,  "az": 270, "dist": 0.14},
  {"t": 3,  "az": 270, "dist": 0.14},
  {"t": 5,  "az": 90,  "dist": 0.14, "via": "front", "pass_dist": 0.4},
  {"t": 9,  "az": 180, "dist": 0.6},
  {"t": 14, "az": 0,   "dist": 1.2}
]
```

`via` 可以是 `short` / `front` / `back`，决定从前面还是后面绕过去；`pass_dist` 是绕行途中离头的最小距离。

## 其他常用参数

- `--channel auto|left|right|mix`：立体声取哪个声道。如果输入本身已经做过左右声像（比如原视频），只取一个声道会丢掉另一侧的内容，程序会提示你改用 `mix`。
- `--room none|real|treated|bedroom|living`，`--wet ±dB`：房间声学。默认风格为 `none`，`--style ku100` 为 `real`。想要空间感可以用 `real` 或 `bedroom`。
- `--warmth 6`：凑近时两耳共同的低频温暖感（dB），设 0 关闭。
- `--micro 1`：自然晃动幅度，设 0 关闭。
- `--level-follow`：响度随位置变化的程度。1 = 物理真实（嘴贴耳朵时比在脸前响约 17 dB，移动起来像"这边消失、那边冒出来"），0 = 处处一样响。默认 sweep 用 0.2，pingpong 用 0.1，orbit 用 0.3，phrase 用 0.5，其他模式用 1。
- `--lufs -16`，`--peak -1`，`--max-gr 8`：响度目标、真峰值上限、限制器最多压多少 dB。
- `--start` / `--duration`：只处理一段，方便试听。
- `--save-trajectory 轨迹.csv`：导出实际走位，格式为 时间, 方位角, 距离。

## 建议

- 输入越干净越好。程序不会添加底噪，但输入自带的底噪会跟着人声一起移动，可以先用 DeepFilterNet 降噪（`~/ai/qwenasr/DeepFilterNet3/deep-filter`）。
- 必须用耳机听。外放听不出效果。
- HRTF 不是按个人测量的，少数人可能出现前后混淆；运动和房间声能明显减轻这个问题。
- 声源只在耳朵高度的水平面上移动（近场实测数据只有水平面）；房间反射包含上下方向。

## 数据与许可

`hrtf/` 中的数据来自 TH Köln 的 Spherical Near-Field HRIR Compilation of the Neumann KU100，作者 J. M. Arend、A. Neidhardt、C. Pörschmann，[Zenodo 4297951](https://zenodo.org/records/4297951)，CC BY 4.0。程序第一次运行时会自动下载这些数据。`ku100_tables_v3.npz` 是预处理缓存，删掉后会自动重建。
