# 界面使用说明（Rust 版）

构建和各系统的安装见[构建、发布与开发](development.md)，命令行用法见[命令行](app-cli.md)。

## 启动与配置文件

不带参数启动就是图形界面。界面文字默认中文，右上角可切换英文和明暗主题；关闭时会记住所有设置。

配置自动保存到**启动时的当前工作目录**中的 `auto-asmr.ron`，约每 30 秒保存一次，正常关闭时也会保存，下次启动从同一位置读取。双击 EXE 时通常就是 EXE 所在目录；从终端启动时则是终端的当前目录。该目录需要有写入权限。


右上角的**导出配置**可将当前效果参数、音频设备选择、缓冲、语言、页签和文件输出设置保存为 `.ron` 文件，无需等待自动保存。

右上角的**导入配置**选择一个 `.ron` 文件（导出的文件，或别处复制来的 `auto-asmr.ron`），立即生效，不用重启：正在运行的实时处理或试听会先停止，参数、设备、缓冲等全部换成文件里的设置，文件里没有的项用默认值。读取失败时底部状态栏显示原因，当前设置不变。导入后的设置照常自动保存。

所选音频路径、截取起点和时长、多音频合成里各音频的位置不保存；窗口和主题状态仅随自动保存记录。

窗口右下角的「给个star」打开本项目的 GitHub 页面（<https://github.com/nasuiyile/auto-asmr>），觉得好用欢迎点个 Star。

## 实时模式

1. **音频设备**：程序自动查找本机设备，在下拉框里选输入（麦克风）和输出。插拔设备后点"重载设备列表"。
2. **缓冲**：越小延迟越低；出现爆音就调大。默认 256 帧。
3. 点**开始**。"输出效果 / 监听原声"可以随时切换，对比处理前后。
4. 右侧所有参数都可以边说话边调，立即生效。
5. 麦克风有底噪时，把窗口左下角的**降噪**滑条往右拖（0–100，0 = 关闭，见下面的参数表）。
6. 想自己决定声音在哪儿：勾上位置图下面的**手动摆位**。自动移动全部停掉（穿梭、忽远忽近、自动上下、自然晃动），声源停在你摆的位置——在位置图里点一下或拖动圆点改方位和距离，在图右侧的竖条上拖改高度（双击竖条回到与耳朵齐平）。声音会用零点几秒平滑地跟过去，不会跳，也没有咔嗒声；运行中勾上时，声源就停在此刻所在的位置。取消勾选后回到原来的自动模式，从当前位置接着走。
7. 想立体地看声源在头的哪个位置：勾上位置图下面的 **3D 视图**（默认不显示），会弹出一个小窗口。**右键**拖动旋转视角，**左键**点或拖动直接移动声源（在垂直于视线的平面里移动：从头顶看改前后左右，从侧面看改高低；没在手动摆位时会自动切到手动，从声源此刻的位置开始），滚轮缩放，右键双击复位视角；上方按钮可以直接切到背后、正面、头顶、左侧、右侧。图里有人头（鼻子朝前、两只耳朵）、耳朵高度的水平面和距离圈；声源到这个平面画了垂线和影子，从头到声源画了虚线；手动摆位时蓝圈是目标位置。读数的“上 / 下”和“离耳”与左边位置图的口径相同。窗口关掉时完全不绘制，不占资源。

界面会显示算法延迟、估计的总延迟、每次回调的处理时间和断流次数；俯视图上能看到"说话人"此刻在你头边的位置。

延迟的构成（48 kHz）：

| 部分 | 时长 |
|---|---|
| 算法本身（分数延时插值 0.25 ms + 限制器前瞻约 2.1 ms） | 2.4 ms |
| 开启输入降噪时再加 | 20 ms |
| 输入缓冲 + 环形缓冲 + 输出缓冲（256 帧时） | 约 9 ms |
| 声卡驱动自身 | 取决于设备 |

处理量很小：每 128 个样本一块，平均 22 µs（Apple M 系列单核约 0.8%）；加上真实房间、降噪、去齿音、轻声化约 39 µs（约 1.5%）。

实时模式和文件模式有三点不同：

- **话少时也一直在动**。文件模式里动作严格跟着说话走：停顿时几乎不动，下一句从原位置接着说。直播时话少，或者麦克风底噪大、声音轻，说话检测认不出来，声音就会长时间停在一只耳朵边。所以实时模式里停顿超过 1 秒，动作就恢复正常速度；1 秒以内的短停顿仍然放慢。想让它完全不管说话、按固定节奏走，把"停顿时的动作"调到 1。
- 声音突然变大时，说话人是听到之后才往后让（文件模式能"预读"，会提前约 0.8 秒让开）。
- 响度靠"自动响度"慢慢拉到目标，而不是整段精确归一化。

## 文件转换

界面里点「添加文件…」（可以多选）或「添加文件夹…」，也可以把文件 / 文件夹拖进窗口（可以一次拖多个），文件会排进列表；可以设置取哪个声道、从第几秒开始、处理多少秒、目标响度和位深，对列表里所有文件都生效。点列表里的某一行选中它用来试听，点行首的 × 从列表移除。添加文件夹时只取这一层的音频文件，跳过本程序输出的 `_asmr` 文件。

- **试听**：用实时引擎直接播放，可以边听边调参数，满意后再转换。
- **试听位置**：选好文件并完成解码后，点击或拖动播放滑块就会自动试听该位置的处理效果，播放中也可以前后拖动；停止后保留当前位置。试听位置与“从第几秒 / 处理多少秒”的转换范围分别设置，拖动试听不会改变导出范围。
- **转换并保存**：两遍处理，精确归一化到目标响度（默认 −16 LUFS），真峰值不超过上限。60 秒音频约 0.7 秒，10 分钟约 6 秒。
- **批量转换**：列表里有多个文件时按钮变成「全部转换并保存（N）」。输出默认放在各自源文件旁边（`原名_asmr.wav`），也可以用「输出文件夹…」统一放到一个文件夹；重名时自动加 `_2`、`_3`，不会覆盖输入文件。每行显示等待 / 进度 / 完成 / 失败（鼠标移上去看输出位置或失败原因），列表下面是按时长加权的总进度和预计剩余时间；取消后正在转换的文件中止、写了一半的输出会删掉。
- **多线程**：单个文件的处理是连续有状态的（走位、随机数、响度测量都依赖前面的样本），切段并行会改变结果，所以按"文件"并行：「同时转换」默认等于 CPU 逻辑核数，每个文件占一个核，长的文件先处理，各核尽量同时结束。实测 7 个文件各 120 秒：1 个线程 13.4 秒，7 个线程 2.8 秒。每个文件整段读进内存，长音频每小时约 0.7 GB，内存紧张时调小并行数。并行转换的结果与逐个转换逐字节相同。

### 多音频合成

几个音频同时播放、各在头边的一个位置，比如两个人一个贴着左耳、一个贴着右耳同时说话。

1. 把要合成的音频加进列表（最多 4 个，列表里更多的文件不参与），勾上列表下面的**多音频合成**。
2. 每个音频自动分到一个位置：两个时一个在左耳、一个在右耳（离得最远），第 3、4 个放在正前、正后方约 35 cm。列表每行前面的彩色编号就是它在位置图里的颜色；行尾可以从下拉框换位置（左耳、右耳、正前、正后、左前、右前、左后、右后），或者直接在位置图上拖它的圆圈，摆到任意方向和远近。
3. 各音频先自动对齐到一样响（按 BS.1770 积分响度），行尾的 dB 是在这之上的加减，比如把背景声压低 10 dB。
4. 点**试听**，几个音频一起播放；播放中可以拖位置、改音量、调右侧参数，立即生效。点**合成并保存**输出一个双耳 WAV，默认放在第一个音频旁边，名字是 `第一个音频名_mix_asmr.wav`，可以用「输出到…」另选；长度按最长的那个音频，「从第几秒 / 处理多少秒」对每个音频都一样。

勾上多音频合成后，下面一行的**排布**有两种：

- **各自固定**（默认）：每个音频固定在自己的位置（上面第 2 步），不会跑到别的音频那边去；"左右移动"不起作用，忽远忽近、上下、自然晃动照常，而且每个音频各走各的节奏（随机种子错开）。
- **一起移动**：几个音频按右侧"左右移动"的方式（穿梭、随机走位、环绕、固定、手动）一起走，彼此始终相隔 360°/个数。两个时正好在头的两侧相对：一个贴左耳时另一个贴右耳，换边时一个从脸前、一个从脑后绕过去，不会撞在一起；环绕时几个音频均匀分布在一圈上一起转。几个音频共用一个说话时钟——任何一个在说话就按真实时间走，都停下时一起放慢——所以步调完全一致。列表里的位置下拉框换成它相对 1 号转过的角度（两个时是 +180°），只有音量可调；"手动"时在位置图上拖任意一个，整组一起挪。试听中切换排布，会从当前位置重新开始。

  实测两段真实人声（60 秒，只留其中一个音频听）：两个音频的左右差各自在 −56…+58 dB 之间来回，两者的相关系数 −0.98，没有一个 0.5 秒段两人偏在同一侧；只有一个人在说话时，它的走位与单独转换这个文件完全相同。

#### 自动平衡（让左右两边差不多大）

各音频本来就按整段的平均响度对齐，但整段一样响不等于每一刻都一样响：两个声音各自忽远忽近，常常一个退开了、另一个正贴着耳朵；内容本身也有响有轻（一段在副歌、另一段在主歌）。**排布**那一行右边的**自动平衡**滑条（0–100%，0 = 关）按每个声音**此刻听起来多响**往它们的平均拉：

- 此刻多响 = 输入的 3 秒短时响度（只算出声的部分，由整段事先算好）+ 它此刻的位置带来的增益（引擎输出与输入的能量之比，0.3 秒平滑，只跟位置有关）。在空间化之后、相加之前补，最多 ±15 dB，0.25 秒平滑过渡。
- 100% = 一样响，50% = 差距减半。停顿里的声音不往上拉（沿用停顿前的增益），不会把底噪提上来；几个声音一起变轻时不动。
- 一个声音单独退开时也会被补回一部分，所以忽远忽近的响度变化会变小，强度越大越明显；方向、远耳、音色这些远近线索不变。想保留更多忽远忽近的响度起伏，就用 50% 左右。
- 试听时实时生效（拖滑条、拖播放条都立即跟上）；合成完成后的说明里有平衡前后几个声音之间的响度差。

实测（两版《精卫》对齐后合成，各自固定一左一右，全长 2 分钟）：输出左右两边每 3 秒的响度差，关闭时中位 2.3 dB、90% 10.1 dB、最大 15.2 dB；50% 时 1.4 / 5.9 / 9.5 dB；100% 时 1.0 / 2.6 / 5.5 dB。两段不同的人声（60 秒）在两人同时说话时的响度差从中位 2.5 dB、90% 7.8 dB 降到 1.2 / 3.7 dB。滑条为 0 时输出与没有这个功能时逐字节相同。

#### 自动对齐（同一首歌的几个版本）

要合成的是同一首歌的不同版本时（比如一段前奏长、一段前奏短，或者一段摇滚版、一段 DJ 版），勾上排布下面的**自动对齐**：

- 程序按旋律、和弦和节奏找到它们一起开始唱的地方，从那里叠加；对不上的开头和结尾直接裁掉，裁开的地方淡入淡出 10 ms，不会咔嗒。
- 勾选框下面写出每段从哪里开始用、裁掉多少，例如"1. 摇滚版.m4a：从 0:06.22 开始（裁掉开头 6.22 s），结尾不裁；2. DJ 版.m4a：开头不裁，用到 2:03.02（裁掉结尾 14.16 s）"。合成完成后的说明里也有这几行。
- **试听**和**合成并保存**用的是同一份对齐结果。播放条显示"试听位置（对齐后）"，「从第几秒 / 处理多少秒」也按对齐之后的时间算。试听中勾上或取消，会停在同一处音乐接着播。
- 同一份音源剪出来的（一段带前奏、一段不带，转没转过码都行）对齐到逐个样本；编曲不同的版本对齐到约 1–2 ms。两段速度不完全一样时会提示"叠加后会慢慢错开"。
- 几段对不上（不像同一首歌）时不裁剪，按原样合成，并在下面说明原因。

做法是以第 1 段为基准：先按 20 ms 一帧的色度（12 个音级）和频带能量，在所有偏移上比整首歌，得分按两段全长归一化，所以副歌重复也不会对错位置；再在附近 ±80 ms 内按 2 ms 一帧的起音包络细找；最后在几处 2 秒的窗口里直接比波形，波形一致时取逐样本的结果。两首 2 分钟的歌约 0.3 秒，两段 10 分钟的音频约 0.5 秒。

实测：同一首《精卫》的摇滚版（BV1naFvzEEuA）和 DJ 版（BV1S66jBhEik），找到摇滚版晚 6.221 s，最好的偏移比次好的得分高 2.3 倍；整首歌上分段核对，偏移前后只差 3 ms。把 DJ 版剪掉前 17.3 s 存成 FLAC，对出 17.3000 s；转成 44.1 kHz 的 MP3，对出 17.2749 s（差的 25 ms 是 MP3 编码器加在开头的延时，内容确实在那里），两者都是逐样本。拿歌和 ASMR 人声对、拿两段不相干的人声对，都判为对不上。

其余参数（贴耳感、房间、耳廓、降噪……）对每个音频都一样。每个音频各用一个引擎：试听时 2 个音频约占单核 2.8%（一起移动约 2.5%）、4 个约 4.8%。保存时，各自固定的几个引擎各用一个核并行，两个各 10 分钟的音频约 12 秒；一起移动的几个引擎要逐块同步，按顺序算，约 18 秒。

支持 wav / m4a / mp3 / flac / ogg 等常见格式（symphonia 解码）；输出 48 kHz 立体声 WAV。立体声输入只取一个声道，默认取更响的那个。

## 参数

| 分组 | 参数 | 作用 |
|---|---|---|
| 风格 | 贴耳加强 / KU100 实录 / 掏耳 | 一键设置，三个内置预设。贴耳加强（默认）：嘴离耳约 1.7 cm，另一只耳朵几乎听不到，不加房间，左右耳慢慢穿梭。KU100 实录：按真实 KU100 轻语录音标定，远耳听得到、真实房间、KU100 原机音色；像真人一样随机走位，约三分之一的停留在正面，贴耳时离耳约 2–4 cm；气流更明显，齿音更柔。掏耳：给棉签、挖耳勺、刮擦这类触发音用，见下面的[掏耳预设](#掏耳预设)。按钮会把贴耳感、入耳、左右移动、忽远忽近、上下、房间与回放、去齿音 / 轻声化和目标响度一起设成该风格的值（所以按哪个都得到确定的结果）；降噪、响应阈值、耳廓、自动响度开关、输出增益、峰值上限、随机种子不动。 |
| 贴耳感 | 贴耳距离、远耳压低、临场感、暗度、温暖感、近耳低频、远耳低频削减、气声增强、气流扑耳、耳甲共鸣、贴耳轻声、嘴的大小、远耳高频遮挡 | 贴耳的程度和音色。气声增强把嗓音里轻的送气声提上来（响的齿音不提）；气流扑耳是送气时气流扑到耳朵上的低频脉冲（"耳朵痒"）；耳甲共鸣是近耳 4.3 kHz 的耳甲腔共振。三样都只在贴耳时出现，只用嗓音自己的气声，不加噪声；拖到 0 就是关闭。贴耳轻声是凑到耳边时把嗓音均衡成"放轻声音"；嘴的大小把嘴当成约 2 cm 宽的开口而不是一个点，贴耳时耳廓的窄谷变浅；远耳高频遮挡是贴耳时另一只耳朵的高频再压低一些。依据见[效果与依据](effects.md)。 |
| 入耳（掏耳） | 入耳深度、进出节奏、随机程度、耳道共鸣、耳内低频、堵耳闷感 | 声源贴到耳朵上之后再伸进耳道。入耳深度是最深伸进去多少（0 = 不进耳道，这一组都不起作用，界面上默认折叠）；只有贴在耳朵上时才伸得进去，换边前先退出来。耳道共鸣：伸得越深共振越高（约 3 → 11 kHz），听得出进出的深浅。耳内低频：摩擦 / 触碰在耳道里形成的隆隆声，由输入自己的包络导出，不加噪声。堵耳闷感：伸进去时近耳 2.5 kHz 以上压低。伸进耳道时，位置图左上角的"离耳"读数换成"入耳"深度。 |
| 左右移动 | 模式（穿梭 / 随机走位 / 环绕 / 固定 / 手动）、移动频率、停留时间、移动时间、随机程度、正面比例、从远处凑近、贴耳角度、从哪里绕 | 左右切换的方式和节奏。随机程度为 0 时完全规律。正面比例（随机走位）：每次停下来有多大比例停在正前方，其余停在耳边、侧前、侧后。"手动"就是位置图下面的"手动摆位"：没有任何自动移动，位置由你拖动决定（也可以用这里的方位角、离头距离、高度三个滑条）；文件转换时相当于固定在这个位置。 |
| 忽远忽近 | 幅度、节奏、随机程度、跟随音量、退开时的音量、停顿时的动作、自然晃动 | 说话人在耳边凑近、往后让。跟随音量：声音大时往后让、轻声时更贴近。停顿时的动作 0.13 = 停顿里几乎不动，下一句从原位置接着说（实时模式下停顿超过 1 秒会恢复）。 |
| 上下 | 高度、自动上下、节奏、随机程度、从头顶绕 | 高度：嘴在耳朵上方（正）或下方（负）多少度，离耳朵的距离不变。自动上下：嘴在耳朵上方 / 下方之间慢慢换位置，0 = 关闭。从头顶绕：换耳时不从脸前 / 脑后绕，而是从头顶绕过去的概率。上下只靠耳廓对 5 kHz 以上高频的染色，比左右和远近弱，因人而异。 |
| KU100 临场感 | 真实房间、房间声大小、耳廓、回放补偿 | 真实房间是 TH Köln 用同一个 KU100 实测的；耳廓可以从 KU100 自己的耳廓换成 7 只真人耳廓（HUTUBS 实测，CC BY 4.0）：自己听时挑前后、上下最分得清的那只，给别人听建议仍用 KU100。回放补偿可选通用扩散场、KU100 原机音色，或 23 款耳机型号。 |
| 降噪（窗口左下角） | 一个 0–100 的滑条 | 输入降噪（RNNoise，纯 CPU），在空间化之前做，实时和文件转换都有效。数值 = 底噪最多压低多少分贝；0 = 关闭，100 = 不设上限，60 以上基本没有区别。风扇、空调这类稳定的底噪，设多少就降多少；嘶嘶的白噪声，降噪器自己最多只能压低二十多分贝。人声音量不变，气声的高频会被削掉一点（轻语实测：设 6 时约 1 dB，设 100 时约 2.6 dB），所以够用就行，不必拖到头。开启后延迟增加 20 ms。 |
| 人声处理 | 响应阈值、去齿音、轻声化 | 响应阈值以下的输入当作静音。都不改变嗓音本身。 |
| 输出 | 自动响度、目标响度、输出增益、峰值上限、随机种子 | 实时 / 试听时自动响度慢慢把音量拉到目标；限制器保证真峰值不超过上限。 |

每个参数在界面上悬停都有说明。各项的依据和文献见[效果与依据](effects.md)。

点击效果滑块旁边的数字可以手动输入，按 Enter 确认。滑轨显示常用范围，手输或拖动数字可以超出该范围，自动保存和导出也会保留输入值；播放进度和降噪（100 已表示不设上限）仍使用各自的固定范围。声源距离等物理量仍受算法支持范围限制（到头中心 0.095–3 米）。“气流扑耳”使用倍数：0 = 关闭，1 倍 = 标准，滑轨上限为 8 倍，也可手输更高数值。

## 掏耳预设

点右侧"风格"里的**掏耳**。它把棉签、挖耳勺、刮擦这类触发音做成"在耳朵里掏"的效果：声音只在一只耳朵里，伸进耳道进进出出（耳道共鸣跟着滑动），带很强的耳内低频；每只耳朵约 40 秒才换边，换边时先退出来。按两段 KU100 掏耳实录标定，做法见[效果与依据 · 掏耳](effects.md#掏耳入耳--style-earclean)。

- **输入**：干的摩擦 / 刮擦声（隔着一点空气录的，或者对着话筒附近的东西刮、蹭）。不是给人声用的。实时模式下就是对着话筒做这些动作。
- **降噪**：窗口左下角的降噪会把这类声音当噪声压掉，掏耳时拖到 0 或调低。
- **低频太重 / 太轻**：调"耳内低频"。输入本身低频就重（直接摩擦话筒）时再把"温暖感""近耳低频"调低；输入很干、听着单薄时把"温暖感"加到 9–12 dB。
- **换边快慢**：调"停留时间"（预设 40 秒）。想自己决定掏哪只耳朵，勾"手动摆位"，把声源拖到那只耳朵上——贴上去就会伸到设定的深度，拖"入耳深度"滑条就是手动进出。
- **两只耳朵同时掏**：用[多音频合成](#多音频合成)放两段不同的素材，一段在左耳、一段在右耳（同一段素材放两边会跑到脑袋中间）。
- **响度**：掏耳的能量集中在低频，峰值高而响度读数低，所以点"掏耳"时文件转换的目标响度会一起改成 −20 LUFS（切回别的风格时恢复 −16），实时 / 试听的自动响度目标是 −23 LUFS。
- **耳机**：低频要耳机放得出来；很多小耳塞 40 Hz 以下出不来。
